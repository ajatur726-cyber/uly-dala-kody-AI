GITHUB PAGES-КЕ ЖҮКТЕУ
1. ZIP архивін компьютерде ашыңыз.
2. Архивтің өзін емес, ішіндегі index.html файлын және барлық қалташаларды репозиторийдің түбіріне жүктеңіз.
3. Файл атауларын және қалташалардың орналасуын өзгертпеңіз.
4. GitHub Pages қосылған репозиторийде өзгерістер жарияланған соң басты бетті ашыңыз.
Басты бет → төрт бөлім → сынып/санат → тақырып/құрал.
Интернет сілтемелері мен бейнелерді ашу үшін интернет қажет.
Беттегі материалдар, тапсырмалар реті және безендірілу сақталды. Қайталанатын жеке файл нұсқалары негізгі беттерге бағытталады.
