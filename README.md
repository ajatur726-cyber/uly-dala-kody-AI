# Нормативтік құқықтық база

56 нормативтік акт, әрқайсысына жеке қалташа және HTML бет.

## GitHub Pages-ке жариялау
1. ZIP файлын компьютерде ашыңыз.
2. Репозиторийде Add file → Upload files таңдаңыз.
3. index.html, assets, documents, documents.json, source.docx және .nojekyll файлдарын құрылымын сақтап репозиторийдің түбіріне салыңыз. ZIP файлының өзін салмаңыз.
4. Commit changes басыңыз.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Жариялау аяқталған соң Pages бөліміндегі сілтемені ашыңыз.

Бұрыннан бар сайтқа кіріктіру: осы жинақты normativtik-quqyqtyq-baza қалтасына салып, басты бетке <a href="normativtik-quqyqtyq-baza/index.html">Нормативтік құқықтық база</a> сілтемесін қосыңыз.

Жергілікті қарау: index.html файлын браузерде ашыңыз. Навигация интернетсіз істейді; сыртқы құжаттарды ашу үшін интернет керек.

Атаулар, деректемелер және сілтемелер бастапқы құжаттан алынды. URL ішіндегі бос орындар түзетілді. Актілердің заңдық мәртебесі және сыртқы серверлердің қолжетімділігі тексерілмеген. 5-тармақта қысқа сілтеме, 22-тармақта материалдар бөліміне сілтеме сақталған. Толық акт мәтіндері архивке енгізілген жоқ.

## Жаңартылған құрылым
Басты бетте үш жабық қалташа: Заң (Конституция және 3 заң), Жарлық (1), Қаулы (6 қаулы және 45 бұйрық). Бұйрықтар өз құқықтық түрін сақтап, «Бұйрықтар» ішкі бөлімінде көрсетілген. Топты ашқанда тізім мен сол топтан іздеу көрінеді.

## Бөлек беттерге өту
Басты беттегі Заң, Жарлық, Қаулы қалташалары zan.html, zharlyq.html, qauly.html беттерін ашады. Құжаттар тізімі сол беттерде көрсетіледі. Осы үш жаңа HTML файлын да GitHub-қа жүктеңіз.
