# Тәрбие әлемі | 1–11 сынып

Ұран: **Құндылықтан — ізгі әрекетке**.

Қазақ тіліндегі авторлық әдістемелік жинақ. Әр сыныпта 30 тақырып: барлығы 330 тәрбие сағаты, 1650 жағдаят, 330 жұптық, 330 топтық және 330 шығармашылық тапсырма, 1650 талқылау сұрағы, 330 кері байланыс формасы бар.

## Қай файлды ашу керек?

- **index.html** — қалталар мен жеке беттерден тұратын негізгі сайт. Интернетсіз де екі рет басып ашуға болады. assets және classes қалталарын қатар ұстаңыз.
- **tarbie-alemi.html** — барлық мазмұны бір файлға біріктірілген нұсқа. Қосымша файл қажет емес; JavaScript қосулы болуы керек. Бұл файлды бөлек жіберуге және GitHub Pages-ке жүктеуге болады.
- **TOPIC-MATRIX-KK.md** — барлық 11 сыныптың тақырып атауларының матрицасы.
- **QA-REPORT.json** — орындалған тексерулер мен олардың шектері.

## Негізгі файл құрылымы

```text

tarbie-alemi.html
```

Негізгі нұсқада 342 HTML бет: басты бет, 11 сынып беті, 330 тақырып беті. Бұған қосымша бір файлдық tarbie-alemi.html бар. Әр сынып пен әр тақырып жеке қалта/бет арқылы ашылады. Екі нұсқада мазмұн бірдей.

## GitHub Pages-ке жүктеу

1. ZIP архивін компьютерге жүктеп, толық ашыңыз.
2. GitHub-та жаңа репозиторий жасаңыз немесе қажетті репозиторийді ашыңыз.
3. Add file → Upload files арқылы index.html файлын, assets және classes қалталарын, .nojekyll және қалған файлдарды негізгі қалтаға салыңыз. Ішкі қалталардың құрылымын сақтаңыз. ZIP архивінің өзін салу сайтты ашпайды.
4. Commit changes басыңыз.
5. Settings → Pages → Build and deployment бөлімінде Deploy from a branch таңдаңыз.
6. Branch: main; Folder: / (root); Save.
7. Жариялану аяқталғанда Pages бөлімінде көрсетілген сілтемені ашыңыз.

Егер бар сайтқа жаңа бөлім ретінде қоссаңыз, барлық файлды **tarbie** ішкі қалтасына орналастырыңыз. Басты мәзірге `<a href="tarbie/index.html">Тәрбие әлемі</a>` салыстырмалы сілтемесін қосыңыз. Қазіргі басты бетті алмастырмаңыз.

Бір файлдық нұсқаны ғана қолдансаңыз, tarbie-alemi.html файлын жүктеңіз. Оны репозиторийдің басты беті ету үшін index.html деп атауға болады; бар index.html-ді алмастырмас бұрын оның көшірмесін сақтаңыз.

## Қолдану

Сыныпты ашыңыз → тақырыпты таңдаңыз → «Түсіндірме», «Тапсырмалар», «Шығармашылық ресурс», «Кері байланыс» немесе «Мұғалімге» қойындысына өтіңіз.

Әр сабақта мақсат, үш күтілетін нәтиже, шағын түсіндірме, негізгі ұғымдар, бес жағдаят, жұптық, топтық, шығармашылық жұмыс, бес сұрақ, өзіндік тексеру және кері байланыс бар. A1–A8 белгілері тапсырмаларды ажыратады. Мұғалім жауаптары бастапқыда жабық тұрады. Сабақтар үшін 40 минуттық ұсыныс берілген; негізгі кезеңдер қосындысы — дәл 40 минут. Қосымша қағаз әңгіме ресурсы шығармашылық жұмыстың орнына немесе бөлек уақытта қолданылады.

1–2-сыныпта мұғалім мәтінді оқиды, жауап белгіше, сурет, бір сөз не ауызша беріледі. Әр сыныпта ойлау әрекеті өзгеше: таңдау, реттеу, диалог, себеп-салдар, қадамдық шешім, баламаларды салыстыру, құрдас қысымын талдау, мүдделерді ескеру, дәлел тексеру, жоспарлау және ұзақ мерзімді әсерді бағалау.

## Кері байланыс

- Аты-жөн және өзге жеке мәлімет сұралмайды.
- Оқушылар бір құрылғыда кезекпен белгіше таңдап, үш қысқа сұраққа жауап бере алады.
- «Кері байланысты тіркеу» жауапты ашық бет сессиясына қосып, өрістерді келесі оқушы үшін тазартады.
- Өзіндік бағалау бойынша санақ пен анонимді жауаптар көрсетіледі.
- «Жауаптарды TXT жүктеу» арқылы мұғалім жауаптарды бөлек файлға алады.
- Бет жаңарса немесе басқа бет ашылса, жүктелмеген жауаптар жоғалады. Жауап мәтіні автоматты түрде localStorage-ға сақталмайды.
- Басқа телефондардан берілген жауаптар автоматты біріктірілмейді. Бұл — аккаунтсыз және серверсіз жергілікті жинақ.

## Таңдаулы және қаралған тақырыптар

Тақырып ішіндегі батырмалармен белгіленеді. Белгілер ғана сол браузердің localStorage жадында сақталады. Қаралған белгісі мұғалім не қолданушы батырманы басқанда қойылады; бет ашылғаннан-ақ орындалды деп саналмайды. Құрылғыда сақтау бұғатталса, бұл туралы хабар беріледі. Басты беттегі «Таңдаулы мен қаралған белгілерді тазалау» оларды өшіреді.

## Басып шығару / PDF

Тақырыптағы «Басып шығару / PDF» батырмасын басыңыз. Браузер терезесінде PDF ретінде сақтау мүмкіндігін таңдаңыз. Барлық сабақ қойындылары баспаға шығады. Жабық мұғалім жауаптары басылмайды; қажет жауаптарды баспаға дейін ашыңыз. Іздеу, мәзір мен басқару батырмалары баспада жасырылған. Кері байланыс өрістерінің ағымдағы мәтіні баспаға қосылады.

## Дереккөздер мен қауіпсіздік

Жағдаяттар мен тапсырмалар авторлық әдістемелік ұсыныс болып табылады. Олар ресми бағдарламаның сөзбе-сөз талабы ретінде берілмейді. Ресми тірек дереккөздер және тексеру күні әр тиісті сабақтың «Мұғалімге» бөлімінде және басты бетте көрсетілген.

Тексеру күні: **25.10.2026**. «Әділет» АҚЖ-дағы мерекелер туралы заңның қолданыстағы мәтіні, мерекелік күндердің тізбесі, баланың құқықтары туралы заң, Ақордадағы рәміздер беті, UNICEF-тің кибербуллинг материалы және gov.kz-тегі мұғалімдер күні туралы хабар қолданылды. Құқықтық құжаттар мен күндер өзгеруі мүмкін; нақты өткізерде тиісті ресми мәтінді қайта қараңыз. Тексерілген 2026 жылғы мерекелер туралы заңда Конституция күні **15 наурыз** деп көрсетілген. Аналар күні — мамырдың екінші жексенбісі; 8 наурыз — Халықаралық әйелдер күні.

Тексерілген бейне әзірге қосылмаған. Әр сабақта толық дайын, интернетсіз үш көріністі қағаз әңгіме баламасы бар. Жалған бейнесілтеме не YouTube іздеу нәтижесі нақты бейне ретінде ұсынылмайды.

Баланың шынайы оқиғасын көпшілікке айтқызбаңыз. Буллинг пен кибербуллингте кінә артпаңыз, қорлау көрінісін сахналатпаңыз. Жеке дерек, диагноз, нақты құпиясөз, отбасылық қаржы, жеке хат сұралмайды. Қауіпті жол, әскери, тазалау не дене жаттығуы тәжірибе түрінде орындалмайды. Жол сызбалары мен қаржылық сандар — ойдан шығарылған оқу мысалдары.

## Тексеру нәтижесі

- 11 сынып, әрқайсысында 30 тақырып — тексерілді.
- 330 бірегей тақырып атауы — тексерілді.
- Әр сабақта 5 бөлек жағдаят, жұптық, топтық, шығармашылық тапсырма, 5 сұрақ, 3 рефлексия сұрағы — тексерілді.
- 5742 ішкі файл/фрагмент сілтемесі — қате табылмады.
- Іздеу, сүзгі, бос нәтиже, беттеу, қойындылар, таңдаулы, қаралған белгілері, кері байланыс тіркеу/тазалау, зиянды HTML мәтінін қауіпсіз көрсету, викторина түсіндірмесі және баспа/жүктеу шақырулары — DOM модельдеу арқылы тексерілді.
- Бір файлдық нұсқаның сынып/тақырып навигациясы мен қойындылары — DOM модельдеу арқылы тексерілді.
- Телефонға бейімделетін CSS, көрінетін фокус және қозғалысты азайту ережелері бар.
- Қолдау көрсетілетін браузерлік тексеру ортасы болмағандықтан, нақты браузердегі мобильді көрініс, жүктеу диалогы мен PDF нәтижесі визуалды тексерілмеді.

Сайтқа API кілті, сервер, аккаунт немесе сыртқы кітапхана қажет емес. Сыртқы ресми сілтемелерден басқа негізгі мазмұн интернетсіз қолданылады.
